# tare.

Website for **tare. atelier**: satin scrunchies, hair bonnets, the Mama Mboga tee and tote, and the atelier design pieces. Designed in Nairobi.

A static site with no build step: `index.html` plus the photos in `assets/`.

- **English and Kiswahili**, with a language switch in the top bar
- **Accessibility settings panel**: read aloud, one-tap profiles, text size, dark mode, high contrast and more
- Products and prices are edited in the `products` list near the bottom of `index.html`

To run it locally: `python -m http.server 5173`, then open http://localhost:5173

`client-review/` holds the first-draft screenshots made for client feedback. `index-v1.html` is the first design, kept for reference.
